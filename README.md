
# 📺 Sorting Algorithms Visualizer 

An interactive Sorting Visualizer built using HTML, CSS, and JavaScript to help users understand how sorting algorithms work internally through real-time visual animations.


## 🚀 Features

- Visualizes popular sorting algorithms such as (Bubble Sort,Selection Sort,Insertion Sort,Quick Sort,Merge Sort).
- Adjustable speed control — 1x, 2x, and 4x speed for better visualization.
- Random array generator (up to 50 elements) with input validation.
- Highlights current comparing index and correct sorted position. 
- Clean and responsive UI for smooth user interaction.

## 🛠 Tech Stack
- HTML5	- Structure and layout.
- CSS3 - Styling and responsive UI.
- JavaScript(ES6) - Algorithm logic and visual animations.
- DOM Manipulation - Dynamic bar generation and updates.

## 🏫 Learning Goals & Concepts Covered 
- Practical understanding of sorting algorithms.
- Worked with DOM updates and event handling.
- Used async/await and delay functions to control animation flow.
- Implemented interactive UI logic such as input validation, button control, and state reset.
- Improved JavaScript problem-solving and visualization logic.
  
## 💡 Future Enhancements 
- Add Heap Sort and Shell Sort.
- Display time complexity comparison table.
- Add dark mode theme.
- Show step counter or swap count.
- Convert project to React version.




# 🌤 Live Weather Dashboard

A simple, responsive web application that fetches and displays real-time weather data for any city. Built with plain HTML, CSS, and JavaScript (Fetch API). Ideal for learning API integration, async JavaScript, and responsive UI design.


## 🚀 Features

- Search weather by city name.
- Displays temperature, weather condition, humidity, wind speed and location.
- Real-time data from a public weather API.
- Error handling for invalid input / failed API calls.
- Responsive layout for desktop and mobile.
- Clean, user-friendly UI for quick weather checks.


## 🚀Tech Stack

- HTML5 (Structure and layout)
- CSS3 (responsive styles)
- JavaScript (Fetch API, async/await)


## 💡 Future Enhancements

- Add 5-day forecast & hourly data.
- Allow location-based weather using Geolocation API.
- Add unit toggle (Celsius / Fahrenheit).
- Save recent searches to LocalStorage.
- Add animations, icons, or background changes based on weather.
- Convert to React for component-based structure and easier state handling.
